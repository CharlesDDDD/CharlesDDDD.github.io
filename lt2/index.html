LT2: Linear-Time Looped Transformers

Overview

Looped Transformers (LT) are an elegant idea: instead of stacking many independently-parameterized layers, reuse the same block of weights $T$ times before producing the output token. This gives $T\times$ the effective depth at $1\times$ the parameter count — a compelling handle for parameter-efficient reasoning at inference time.

But there is a catch. Each loop re-runs full quadratic self-attention over the entire sequence. FLOPs grow as $\mathcal{O}(L^2)$ per loop iteration, and the KV-cache grows as $\mathcal{O}(T \cdot L)$ at inference. As you add more loops to get more reasoning depth, the attention cost compounds — exactly where you want to scale, the architecture becomes most expensive.

LT2 (Linear-Time Looped Transformers) asks: can we keep the looping, but cut the attention cost? We replace full softmax attention inside each loop with subquadratic token mixers — linear attention and sparse attention — and find that looping and efficient attention are not just compatible, but genuinely synergistic. The loop changes what the efficient mixer can do, not just how many times it runs.

Subquadratic Attention in Looped Transformers

Architecture formulation

A standard Transformer of depth $N$ stacks $N$ independently-parameterized blocks $\{\mathcal{F}_\ell\}_{\ell=1}^{N}$, where each block applies a token mixer followed by a feed-forward network:

$$\mathcal{F}_\ell(\mathbf{h}) = \mathbf{h}' + \mathrm{FFN}_\ell(\mathbf{h}'), \qquad \mathbf{h}' = \mathbf{h} + \mathrm{MHA}_\ell(\mathbf{h}).$$

A Looped Transformer (LT) reuses these $N$ shared blocks for $T$ iterations:

$$\mathbf{h}^{(0)} = \mathrm{Emb}(\mathbf{x}), \quad \mathbf{h}^{(\tau)} = \bigl(\mathcal{F}_N \circ \cdots \circ \mathcal{F}_1\bigr)\!\bigl(\mathbf{h}^{(\tau-1)}\bigr), \quad \tau = 1, \ldots, T,$$

yielding effective depth $T \cdot N$ with only $N$ unique parameter sets. The problem: each $\mathrm{MHA}_\ell$ costs $\mathcal{O}(L^2)$ FLOPs and the KV-cache at inference is $\mathcal{O}(T \cdot L)$ — both scale linearly with $T$, compounding the cost of each added loop.

LT2 simply replaces the MHA sub-layer with a subquadratic token mixer:

$$\mathcal{F}_\ell(\mathbf{h}) = \mathbf{h}' + \mathrm{FFN}_\ell(\mathbf{h}'), \qquad \mathbf{h}' = \mathbf{h} + \mathrm{LinearMixer}_\ell(\mathbf{h}).$$

The looping structure, weight sharing, and learned per-loop residual gate $\boldsymbol{\rho}_\tau$ all remain: $\mathbf{h}^{(\tau)} = \widetilde{\mathbf{h}}^{(\tau)} + \boldsymbol{\rho}_\tau \odot \mathbf{h}^{(\tau-1)}$. Beyond efficiency, looping turns out to amplify the expressive power of subquadratic mixers in two distinct ways.

Linear attention: rank-$T$ memory update

Frontier linear-attention architectures (GDN, KDA, RWKV7) maintain a fixed-size recurrent state $\mathbf{S}_t \in \mathbb{R}^{d_k \times d_v}$ via a diagonal-plus-low-rank (DPLR) operator:

$$\mathbf{S}_t = \mathbf{A}_t\,\mathbf{S}_{t-1} + \beta_t\,\mathbf{k}_t\mathbf{v}_t^{\top}, \qquad \mathbf{A}_t = \mathrm{Diag}(\boldsymbol{\alpha}_t)\bigl(\mathbf{I} - \beta_t\,\mathbf{k}_t\mathbf{k}_t^{\top}\bigr),$$

where $\boldsymbol{\alpha}_t \in [0,1]^{d_k}$ is a data-dependent diagonal gate and $\mathbf{k}_t \in \mathbb{R}^{d_k}$ is the key projection of $\mathbf{h}_t$. The matrix $\mathbf{A}_t$ is identity plus a rank-1 perturbation. This means a single non-looped DPLR block can only modify recurrent memory along one direction per token — a known expressivity bottleneck for state-tracking tasks.

When the same block is looped $T$ times, each iteration $\tau$ contributes its own DPLR factor $\mathbf{A}_t^{(\tau)}$ acting on the recurrent state at position $t$. The cumulative state-transition operator across all loops is their product:

$$\mathbf{A}_t^{\mathrm{eff}} = \prod_{\tau=1}^{T} \mathbf{A}_t^{(\tau)} = \prod_{\tau=1}^{T} \mathrm{Diag}\!\bigl(\boldsymbol{\alpha}_t^{(\tau)}\bigr) \!\left(\mathbf{I} - \beta_t^{(\tau)}\,\mathbf{k}_t^{(\tau)}\mathbf{k}_t^{(\tau)\top}\right).$$

The expressivity of this product depends critically on the per-loop keys $\{\mathbf{k}_t^{(\tau)}\}_{\tau=1}^{T}$. If all keys are identical, successive loops erase the same direction — no expressivity gain. If instead the per-loop keys are orthogonal (which diverse intermediate representations can approach in practice), the product erases $T$ distinct directions in recurrent memory. The original rank-1 perturbation becomes a rank-$T$ perturbation, directly multiplying the state-tracking capacity of the linear attention block without adding any parameters.

Sparse attention: $\mathcal{O}(Tw)$ receptive field

A sliding-window block with window size $w$ restricts each query at position $t$ to attend only to the $w$ most recent tokens:

$$\mathcal{I}_t^{(1)} = \{t - w + 1, \ldots, t\}.$$

Anything beyond the window is simply invisible — a hard constraint on long-range retrieval. Looping provides a natural remedy. At loop $\tau$, position $t$ attends to a window of loop-$(\tau\!-\!1)$ representations, which have already absorbed information from their own windows one loop earlier. Chaining this argument inductively gives the effective receptive field after $T$ loop iterations:

$$\mathcal{I}_t^{(T)} \supseteq \bigl\{\max(1,\, t - Tw + 1),\, \ldots,\, t\bigr\}, \qquad \bigl|\mathcal{I}_t^{(T)}\bigr| = \mathcal{O}(Tw).$$

$T$ loops of a window-$w$ block reach as far back as $T$ independently-stacked layers of window-$w$ attention — but with $T\times$ fewer parameters. Looping turns compute into context: once $T$ is moderately large, a fixed local window already covers sequences of arbitrary length, making sparse attention a natural partner for looped architectures.

Architecture

LT2's change to the standard Looped Transformer is minimal: swap the MHA sub-layer inside the shared block with a subquadratic token mixer. The looping structure, the weight sharing, and the learned per-loop residual gate all remain identical. We study two base variants and their hybrids.

Variant Mixer Complexity Core benefit from looping
LT2-linear GDN (Gated Delta Net) $\mathcal{O}(L)$ Rank-$T$ recurrent state update; most stable optimizer behavior
LT2-sparse DSA (Dynamic Sparse Attn) $\mathcal{O}(L \log L)$ Effective receptive field grows to $\mathcal{O}(Tw)$ across loops
LT2-hybrid (GDN+DSA) Efficient GDN + Sparse Attn $\mathcal{O}(L)$ Linear branch compresses; sparse branch handles precise retrieval — no full attention needed
LT2-hybrid (Full+GDN) Best Quality Small fraction Full Attn + GDN Near-linear GDN regularizes the loop; sparse full-attention layers handle the hard retrieval cases

For the hybrid variants we explore two axes of mixing: depth-level (interleave different mixers across the layers within a single loop block) and loop-level (use a different mixer type for different loop iterations). We find depth-level mixing substantially more effective — distributing attention across depth matters more than scheduling it across time.

Training Stability Under Looping

A practical concern when sharing weights across loop iterations is optimization stability. The same block runs $T$ times — any pathology in the attention mechanism can compound. We track gradient norms and loss curves throughout pre-training at 1.3B parameters, 100B tokens.

Attention sinks compound across loops

In standard Transformers, softmax attention concentrates mass on a small set of "sink" tokens — typically the first token — which absorb a disproportionate share of attention regardless of content. In a looped model, this is worse: the sink learned in loop $\tau$ is re-injected into loop $\tau\!+\!1$ rather than reset. Each successive iteration starts already biased, and both the first-token attention mass and the maximum residual activation trace a compounding sawtooth pattern across loops.

We adopt a simple fix: a per-head sigmoid gate after SDPA (following Gated Attention). Applied inside the shared block so the gate weights are reused every iteration, it suppresses the sawtooth almost entirely and yields consistent downstream improvements across all softmax-containing LT2 variants.

The pattern is consistent: mixers with data-dependent gating and a delta rule (GDN, and hybrids that include it) train more stably than vanilla full attention under looping. The gate lets the recurrence forget stale state instead of accumulating it; the delta rule bounds updates to recurrent memory. Mixers missing either ingredient are noisier; missing both (RetNet) is unstable.

You Don't Need to Train from Scratch

One practical barrier to adopting new architectures is the training cost. We show that a pre-trained full-attention Looped Transformer (specifically, Ouro-1.4B) can be converted into an LT2-hybrid model through a three-stage distillation recipe — keeping the embeddings, FFN, and norm parameters, and replacing the attention layers with GDN, then restoring a small fraction of full-attention layers.

The three-stage recipe

Stage 1 — Linear pre-alignment (100M tokens). With all attention replaced by GDN, align each GDN block to its teacher's attention output via MSE on the residual stream. This gives the student a warm start that avoids the gradient instability of initializing GDN weights from random at the distillation scale.

Stage 2 — Hybrid logit distillation (600M tokens). Restore the 6 full-attention layers most important for quality (selected by a KL-guided criterion), then distill on the teacher's output logits. The looped setting introduces a new design knob: a per-loop KL weight schedule. We minimize

$$\mathcal{L}_{\mathrm{KD}} = \sum_{\tau=1}^{T} w_t^{(\tau)}\, \mathrm{KL}\!\left(\sigma_{\mathrm{top}\text{-}k}\!\bigl(z_\mathcal{T}^{(\tau)}/T_{\!\mathrm{kd}}\bigr) \,\Big\|\, \sigma_{\mathrm{top}\text{-}k}\!\bigl(z_\mathcal{S}^{(\tau)}/T_{\!\mathrm{kd}}\bigr)\right),$$

where $\sigma_{\mathrm{top}\text{-}k}$ renormalizes the softmax over the teacher's top-$k$ tokens, $z^{(\tau)}_{\mathcal{T}/\mathcal{S}} \in \mathbb{R}^{L \times V}$ are per-loop logits, and $\mathbf{w}_t \in \Delta^{T-1}$ is a weight schedule across loop iterations. We progressively warm up per-loop supervision, then run uniform weights across loops, then switch to final-output supervision only. Per-loop supervision gives a more stable gradient signal and especially improves multi-key retrieval tasks.

Stage 3 — Long-context continuation (600M tokens at 32k length). Continue training on long reasoning sequences to close the gap on mathematical tasks. Progressive length expansion is essential here — jumping directly to 32k length degrades long-context performance.

Limitations and Open Questions

Two directions remain unexplored. First, we study depth-level hybridization (different attention types across layers within a single block) and simple loop-level schedules, but we do not investigate full loop-level hybridization — where different loop iterations use fundamentally distinct attention families rather than just varying masks. Our ablations suggest loop-level mixing underperforms depth-level mixing in current settings, but there may be smarter schedules we have not tried.

Second, we do not design explicit cross-loop state-carry mechanisms. In the current setup, loop iterations communicate only through the residual stream. A principled recurrent state passed explicitly across loop boundaries could further improve long-context modeling, memory reuse, and compute efficiency — especially for the linear attention variants where the recurrent state is already well-defined.
