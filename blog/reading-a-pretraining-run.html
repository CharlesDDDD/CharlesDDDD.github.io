Reading a Pre-training Run

Metrics, definitions, aggregation semantics, and sampling cadence

Chunyuan Deng · September 2026

Contents

A probe is a measurement attached to training. The monitoring stack has three levels: per-step health metrics, periodic tensor diagnostics, and checkpoint evaluation.

A note on “rank.” In this post, a rank is one process in a distributed training job. It does not mean matrix rank.

1. Metric index

The table gives the default monitoring surface. Detailed definitions and aggregation rules follow in later sections.

Cadence rule. Cheap alerting metrics run every step. Tensor scans run every 100 steps. Evaluation runs every 0.5–2% of training. An anomaly triggers denser probes or replay.

Comparison axis. If batch size changes, compare runs by cumulative tokens or estimated floating-point operations, not by step.

2. Core optimization health

Loss

Let $R$ be the number of distributed ranks. Rank $r$ contains $T_r$ token positions. For token $t$ on rank $r$, $\ell_{r,t}$ is its negative log-likelihood and $m_{r,t}$ is 1 for a valid target and 0 otherwise.

Global mean loss $L$. Sum valid-token loss and valid-token count over all ranks, then divide.

$$L = \frac{\sum_{r=1}^{R}\sum_{t=1}^{T_r} m_{r,t}\ell_{r,t}} {\sum_{r=1}^{R}\sum_{t=1}^{T_r} m_{r,t}}.$$

Use $L$ for convergence and scaling comparisons.

Local mean loss $L_r$. Compute the valid-token mean on rank $r$.

$$L_r = \frac{\sum_{t=1}^{T_r}m_{r,t}\ell_{r,t}} {\sum_{t=1}^{T_r}m_{r,t}}.$$

Omit a rank with no valid target; do not record it as zero.

Worst-rank loss $L_{\max}$. Take the maximum local mean over ranks.

$$L_{\max}=\max_{1\le r\le R}L_r.$$

Use $L_{\max}$ to detect a bad worker or unusual data shard hidden by $L$. It is not a maximum over tokens or examples.

Aggregation: do not average $L_r$ when valid-token counts differ. Reduce the loss sum and token count separately, then compute $L$.

Gradient scale

Let $g=(g_1,\ldots,g_P)$ contain all $P$ gradient elements. The index $j$ selects one element. Measure after gradient accumulation and loss-scale removal, but before global clipping.

Global gradient norm $G_2$. Compute the Euclidean norm over all gradient elements.

$$G_2=\sqrt{\sum_{j=1}^{P}g_j^2}.$$

This is the primary gradient-stability signal.

Mean absolute gradient $G_{\mathrm{mean}}$. Average the absolute gradient elements.

$$G_{\mathrm{mean}}=\frac{1}{P}\sum_{j=1}^{P}|g_j|.$$

This tracks typical element scale and is less sensitive to one outlier than $G_{\max}$.

Maximum absolute gradient $G_{\max}$. Take the largest absolute gradient element.

$$G_{\max}=\max_{1\le j\le P}|g_j|.$$

This detects localized explosion that may be diluted in $G_{\mathrm{mean}}$.

Gradient zero fraction $Z_g$. Count exact zeros and divide by the number of gradient elements.

$$Z_g=\frac{1}{P}\sum_{j=1}^{P}\mathbf{1}[g_j=0].$$

The indicator $\mathbf{1}[\mathcal{C}]$ equals 1 when condition $\mathcal{C}$ is true and 0 otherwise. A rise in $Z_g$ can indicate sparse paths, underflow, or parameters receiving no gradient.

Timing: record whether each gradient metric is scaled or unscaled, accumulated or per-microbatch, and before or after clipping.

Spikes

For a positive scalar $x_t$ at step $t$, define $u_t=\log(x_t+\varepsilon)$, where $\varepsilon>0$ is a numerical floor and $\log$ is the natural logarithm. Let $W_t$ contain earlier $u$-values.

Rolling median $q_t$. Use the median of the log-space window as the local baseline.

$$q_t=\operatorname{median}(W_t).$$

The median is robust to isolated spikes.

Median absolute deviation $D_t$. Measure the median distance from the rolling median.

$$D_t=\operatorname{median}_{u\in W_t}|u-q_t|.$$

$D_t$ estimates recent variability without using a variance that a spike can inflate.

Robust spike score $z_t$. Normalize the current deviation by $D_t$.

$$z_t=0.6745\frac{|u_t-q_t|}{D_t+\varepsilon}.$$

The factor 0.6745 calibrates the score for normally distributed log-values. Apply the detector separately to $L$ and $G_2$.

Co-spike indicator $C_t$. Mark a step only when loss and gradient norm both spike.

$$C_t=\mathbf{1}[\text{loss spike at step }t]\, \mathbf{1}[\text{gradient-norm spike at step }t].$$

$C_t=1$ is a higher-confidence instability event than either detector alone.

Thresholds: calibrate the window length and $z_t$ threshold on stable runs. Do not tune them on a single failure.

3. Tensor probes

Let $x=(x_1,\ldots,x_N)$ be a flattened tensor with $N$ scalar elements. The index $j$ selects one element.

Absolute mean. Average the absolute element values.

$$\operatorname{AbsMean}(x)=\frac{1}{N}\sum_{j=1}^{N}|x_j|.$$

This measures typical scale without sign cancellation.

Square mean $M_2$. Average the squared element values.

$$M_2(x)=\frac{1}{N}\sum_{j=1}^{N}x_j^2.$$

$M_2$ is convenient for aggregation because ranks can reduce the squared sum and element count separately.

Root mean square. Take the square root of $M_2$.

$$\operatorname{RMS}(x)=\sqrt{\frac{1}{N}\sum_{j=1}^{N}x_j^2}.$$

RMS measures energy scale and remains comparable across tensors with different element counts.

Absolute maximum. Take the largest absolute element.

$$\operatorname{AbsMax}(x)=\max_{1\le j\le N}|x_j|.$$

This is the fastest indicator of an outlier, overflow, or local numerical explosion.

Zero fraction $Z_x$. Count exact zeros and divide by $N$.

$$Z_x=\frac{1}{N}\sum_{j=1}^{N}\mathbf{1}[x_j=0].$$

$Z_x$ measures sparsity, underflow, and inactive paths. The indicator function was defined in Section 2.

Excess kurtosis $\kappa$. Let $\mu=\frac{1}{N}\sum_{j=1}^{N}x_j$ be the empirical mean. Normalize the fourth central moment by the squared variance.

$$\kappa= \frac{\frac{1}{N}\sum_{j=1}^{N}(x_j-\mu)^4} {\left(\frac{1}{N}\sum_{j=1}^{N}(x_j-\mu)^2\right)^2}-3.$$

Large positive $\kappa$ indicates heavy tails. The metric is undefined when the empirical variance is zero.

Observation points. Measure embeddings, logits, query/key/value tensors, normalized query and key, attention output, feed-forward activations, residual streams, Mixture-of-Experts inputs, parameter gradients, and applied updates. Use distinct names for forward activations and backward gradients.

Distributed reduction: aggregate sums and element counts before computing means. Aggregate maxima with a maximum reduction. Do not average local maxima or ratios whose denominators differ.

Relative update size

Optimizer path. For the same parameter group, record the raw gradient, normalized gradient, preconditioned direction, and final applied update as separate tensors.

This locates the stage that introduces a scale or direction change.

Relative update size $\rho$. Let $w$ be a parameter tensor and $\Delta w$ the update applied to it.

$$\rho=\frac{\operatorname{RMS}(\Delta w)} {\operatorname{RMS}(w)+\varepsilon}.$$

A persistent fall toward zero indicates ineffective updates. A sudden rise indicates an update large relative to the parameter scale.

Naming: specify whether an optimizer tensor is before or after normalization, preconditioning, weight decay, learning-rate scaling, and clipping.

4. Mixture-of-Experts balance

Let $E$ be the number of experts and $c_i$ the number of valid tokens sent to expert $i$, where $1\le i\le E$.

Mean expert load $\bar c$. Average token counts across experts.

$$\bar c=\frac{1}{E}\sum_{i=1}^{E}c_i.$$

$\bar c$ is the balanced-load reference.

Normalized expert load $p_i$. Divide expert $i$'s token count by the total routed-token count.

$$p_i=\frac{c_i}{\sum_{j=1}^{E}c_j}.$$

The symbol $j$ is a dummy index over all experts, and $\sum_i p_i=1$.

Imbalance ratio $I$. Compare the busiest expert with the mean.

$$I=\frac{\max_{1\le i\le E}c_i}{\bar c}.$$

Perfect balance gives $I=1$. Larger values identify routing and compute imbalance.

Excess load $V$. Subtract the balanced baseline from $I$.

$$V=I-1.$$

Perfect balance gives $V=0$. A value of 0.25 means the busiest expert receives 25% more tokens than the mean.

Routing entropy $H$. Compute Shannon entropy from the normalized expert loads.

$$H=-\sum_{i=1}^{E}p_i\log p_i.$$

Lower $H$ means routing is concentrated on fewer experts. The logarithm is natural.

Normalized routing entropy $H_{\mathrm{norm}}$. Divide $H$ by its maximum for $E$ experts.

$$H_{\mathrm{norm}}=\frac{H}{\log E}.$$

$H_{\mathrm{norm}}=0$ means complete concentration; $H_{\mathrm{norm}}=1$ means uniform routing.

Shard imbalance. Apply the definition of $I$ to expert-parallel shard loads. Expert-level balance does not guarantee balanced communication groups.

Masking: exclude padding and invalid tokens. Skip ratios when no valid token reaches the layer.

5. Residual paths

Let $s\in\mathbb{R}^{d}$ be one token's residual-stream vector and $b\in\mathbb{R}^{d}$ the branch output added to it. The set $\mathbb{R}^{d}$ contains $d$-dimensional real vectors, and $d$ is the hidden dimension. Let $a=s+b$ be the updated stream.

Stream norm $N_s$. Measure the incoming residual scale.

$$N_s=\lVert s\rVert_2.$$

Plot $N_s$ across depth to detect residual growth or decay.

Branch norm $N_b$. Measure the branch-output scale.

$$N_b=\lVert b\rVert_2.$$

$N_b$ alone is scale-dependent; compare it with $N_s$.

Relative branch scale $R_b$. Divide branch norm by stream norm.

$$R_b=\frac{N_b}{N_s+\varepsilon}.$$

A small $R_b$ indicates a weak branch; a large value indicates a branch that dominates the existing stream.

For vectors $u$ and $v$, define cosine similarity as

$$\cos(u,v)= \frac{u^\top v}{\lVert u\rVert_2\lVert v\rVert_2+\varepsilon}.$$

The product $u^\top v$ is the dot product, $\lVert\cdot\rVert_2$ is the Euclidean norm, and $\varepsilon>0$ prevents division by zero.

Block importance $B$. Measure the directional change from $s$ to $a$.

$$B=1-\cos(s,a).$$

$B=0$ when the update preserves direction. Larger values indicate a stronger directional change.

Angular distance $A$. Convert cosine similarity to a normalized angle.

$$A=\frac{\arccos(\cos(s,a))}{\pi}.$$

The constant $\pi$ is the circle constant. $A$ lies between 0 and 1.

BF16 no-op fraction $F_{\mathrm{noop}}$. Let $Q_{\mathrm{BF16}}(\cdot)$ round a real value to bfloat16. For feature index $j$, count a nonzero branch update when rounded addition leaves the stream unchanged.

$$F_{\mathrm{noop}}= \frac{1}{d}\sum_{j=1}^{d} \mathbf{1}\!\left[ Q_{\mathrm{BF16}}(s_j+b_j)=Q_{\mathrm{BF16}}(s_j) \ \land\ b_j\ne0 \right].$$

A large value means residual updates are being lost to bfloat16 precision.

Aggregation: compute these metrics per valid token, then report their mean and upper quantiles. Flattening all tokens and features together hides token-level outliers.

6. System health

Let $\tau_r$ be the local step time on rank $r$, and let $\tau=\max_r\tau_r$ be the global wall time of the step.

Token throughput $\operatorname{TPS}$. Let $N_{\mathrm{tok}}$ be the global number of valid tokens processed in one step.

$$\operatorname{TPS}=\frac{N_{\mathrm{tok}}}{\tau}.$$

This is the end-to-end training rate. Include data loading, forward, backward, optimizer, and synchronization in $\tau$.

Compute rate $\Phi$. Let $F_{\mathrm{step}}$ be estimated floating-point operations per step and $D$ the number of accelerator devices.

$$\Phi=\frac{F_{\mathrm{step}}}{D\tau}.$$

$\Phi$ is estimated floating-point operations per second per device. Keep the FLOP estimator fixed across compared runs.

Straggler score $S$. Divide the global step time by the median local step time.

$$S=\frac{\tau}{\operatorname{median}_r(\tau_r)+\varepsilon}.$$

$S$ is close to 1 when ranks progress together. It rises when a slow rank sets the step time.

Allocated memory. Bytes currently held by live tensors.

Use the maximum across ranks to identify the device closest to an out-of-memory failure.

Reserved memory. Bytes held by the device allocator, including cached blocks not currently used by live tensors.

A widening reserved-minus-allocated gap indicates fragmentation or an oversized allocator cache.

Peak memory. Maximum allocated or reserved bytes observed during the measurement interval.

Reset peak counters only at documented boundaries; otherwise adjacent points describe different windows.

Exposed collective wait $W_{\mathrm{comm}}$. Let $\tau_{\mathrm{wait}}$ be collective time on the critical path that is not overlapped with useful computation.

$$W_{\mathrm{comm}}=\frac{\tau_{\mathrm{wait}}}{\tau}.$$

Report collective count and payload with $W_{\mathrm{comm}}$ to separate many small calls from a bandwidth-limited large call.

Hardware telemetry. Record device utilization, power, temperature, clock, process memory, CPU pressure, page faults, and network traffic.

These signals separate model regressions from host, thermal, allocator, and network failures.

Timing: place device events around the real asynchronous wait and read them at an existing synchronization boundary. Adding host synchronization changes the overlap being measured.

Node counters: sample each network interface once per node. Reading it from every local rank multiplies the reported traffic.

7. Evaluation

Let $M$ be the number of valid held-out tokens, $\ell_k$ the negative log-likelihood of token $k$, and $k\in\{1,\ldots,M\}$ the token index.

Mean negative log-likelihood. Average held-out token losses.

$$\operatorname{NLL}=\frac{1}{M}\sum_{k=1}^{M}\ell_k.$$

Lower NLL indicates better held-out language-model fit.

Perplexity. Exponentiate NLL.

$$\operatorname{PPL}=\exp(\operatorname{NLL}).$$

The function $\exp$ is the natural exponential. Perplexity is comparable only when tokenization and loss normalization are fixed.

Bits per byte. Let $N_{\mathrm{byte}}$ be the number of source bytes covered by the held-out tokens.

$$\operatorname{BPB}=\frac{\sum_{k=1}^{M}\ell_k} {N_{\mathrm{byte}}\log 2}.$$

BPB is less sensitive to tokenizer vocabulary and segmentation than token-level perplexity.

Accuracy. Let $Q$ be the number of questions, $\hat a_q$ the prediction for question $q$, and $a_q$ its reference answer.

$$\operatorname{Accuracy}= \frac{1}{Q}\sum_{q=1}^{Q}\mathbf{1}[\hat a_q=a_q].$$

For multiple choice, select $\hat a_q$ using length-normalized option NLL. Keep prompt and answer normalization fixed.

Pass at $k$. For one problem, let $n$ be the number of generated samples, $c$ the number that pass, and $k\le n$ the evaluation sample count.

$$\widehat{\operatorname{pass@}k} =1-\frac{\binom{n-c}{k}}{\binom{n}{k}}.$$

The binomial coefficient $\binom{a}{b}$ counts size-$b$ subsets of $a$ items. If $n-c<k$, the estimate is 1. Pass@1 evaluates one attempt; larger $k$ measures coverage from repeated sampling.

Media gain $\Delta_{\mathrm{media}}$. Let $Q_{\mathrm{with}}$ and $Q_{\mathrm{without}}$ be the same higher-is-better quality score with and without media.

$$\Delta_{\mathrm{media}}= Q_{\mathrm{with}}-Q_{\mathrm{without}}.$$

A positive value measures useful information contributed by the media input.

Intersection over union. Let $\mathcal{P}$ be a predicted region and $\mathcal{G}$ its reference region. Let $|\mathcal{A}|$ denote the area of region $\mathcal{A}$; $\cap$ and $\cup$ denote intersection and union.

$$\operatorname{IoU}= \frac{|\mathcal{P}\cap\mathcal{G}|} {|\mathcal{P}\cup\mathcal{G}|}.$$

IoU is 0 for no overlap and 1 for identical regions.

Comparability: version the dataset, tokenizer, prompt, decoding parameters, post-processing, and judge. A metric change is not interpretable if its evaluation definition also changed.

8. Keep probes inexpensive

  1. Register once. Choose tensor locations while building the model.
  2. Gate early. On an unsampled step, skip the tensor scan itself.
  3. Scan once. Compute several local statistics in one memory pass.
  4. Reduce in batches. Group values by distributed reduction type.
  5. Move only summaries. Keep full tensors on the device.
  6. Write asynchronously. Do not place storage latency on the training path.

Let $K$ be the regular sampling interval in steps. Retain every $K$-th sample, every anomaly step, the warm-up and final steps, and a window around each anomaly. Small runs can use $K=1$. Long runs often use $K$ between 100 and 200 for expensive views. Cheap anomaly detectors should still run every step.

A detector cannot recover expensive measurements from before an event. If that context matters, keep a short in-memory ring buffer or replay the affected batch under denser probes.

Common mistakes

  • Wrong reduction group: data, tensor, pipeline, context, and expert parallel groups have different semantics.
  • Unclear maximum: say whether a maximum is over tensor elements, tokens, examples, or distributed ranks.
  • Ambiguous timing: state whether gradients are scaled, accumulated, clipped, or already updated.
  • Duplicate recomputation: activation checkpointing may execute a forward probe again.
  • Empty shards: absence of data is not a measured zero.
  • Padding: exclude it from token and routing statistics when appropriate.
  • Over-smoothing: keep a faint raw curve behind a smoothed curve so short spikes remain visible.
  • High-cardinality labels: arbitrary parameter names and sample identifiers overwhelm online metric stores.
  • Sensitive artifacts: keep raw samples and token-level traces opt-in, access-controlled, and short-lived.

9. A small dashboard

  1. Run health. Mean and worst-rank loss, $G_2$, spike events, throughput, peak memory, and job state.
  2. Data health. Loss and token share by stable source or modality.
  3. Mixture-of-Experts health. Imbalance ratio $I$, excess load $V$, and normalized routing entropy $H_{\mathrm{norm}}$.
  4. Numerics. RMS, absolute maximum, zero fraction, and clipping state.
  5. Layer detail. Activation scale, gradient contribution, optimizer updates, and residual metrics.
  6. Model quality. Held-out negative log-likelihood and milestone evaluations against cumulative tokens or compute.

The first dashboard contains alerting signals. Higher-cost views are reserved for diagnosis.

The listed cadences are initial settings. Benchmark probe overhead on the target model, parallel configuration, and hardware before increasing frequency.
